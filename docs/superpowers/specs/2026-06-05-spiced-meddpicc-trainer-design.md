# SPICED & MEDDPICC Trainer — Design Spec

## Overview

A locally-hosted web app for sales roleplay training. The user defines a product and a target company, then has a free-form conversation with an AI acting as a representative of that company. A sidebar lets the user fill in fields for each letter of SPICED and MEDDPICC as they discover information during the conversation. At any point, the user can request an AI evaluation of their framework notes — receiving a 0–100% accuracy score, a "ideal answer" for each field, and actionable improvement tips.

---

## Architecture

**Stack:** Python Flask (backend) + HTML/CSS/JS (frontend, no framework)

**File structure:**
```
SPICED & MEDDPICC training/
├── app.py                  # Flask app — routes /chat, /avaliar, /reset
├── .env                    # GEMINI_API_KEY (gitignored)
├── requirements.txt        # flask, google-generativeai, python-dotenv
└── templates/
    └── index.html          # Full UI: sidebar + chat + eval panel
```

**Two Gemini calls per session:**
1. **Roleplay model** (`/chat`) — plays the company representative, responds in character based on the defined scenario. Maintains conversation history in Flask session.
2. **Evaluator model** (`/avaliar`) — receives the full chat transcript + user's framework notes, returns structured JSON with per-field scores and feedback.

API key stored in `.env`, never exposed to the browser.

## Feature 1 — Scenario Setup

On first load (or after "Novo cenário"), a modal/banner prompts:
- **Produto SAP** (text input, e.g. "SAP Signavio")
- **Empresa alvo** (text input, e.g. "Ambev")
- **Setor / contexto** (optional, e.g. "Manufatura, 15k funcionários")

On submit, Flask stores this in the session and generates the roleplay system prompt:

> "You are [Name], a [role] at [company], a [sector] company with [context]. You are talking with a SAP account executive who is trying to understand your business challenges. Stay in character. Respond naturally as a real business executive would — share pain points organically when asked the right questions, don't volunteer everything at once. Speak in the same language the user uses (Portuguese or English)."

The topbar displays the active scenario throughout the session.

## Feature 2 — Roleplay Chat

**Layout:** Sidebar left (280px) + Chat right (flex 1).

**Chat behavior:**
- Messages sent via `POST /chat` with `{message, history}`
- Flask calls Gemini with system prompt + full history + new message
- Response streamed back and displayed with a typing indicator
- The AI representative has a name and role (generated by Gemini at session start based on the company/sector)
- Both Portuguese and English supported — the AI mirrors the user's language

**Chat controls:**
- Text input at the bottom + "Enviar" button (also submits on Enter)
- "↺ Novo cenário" button in topbar resets everything (chat + fields + eval)

---

## Feature 3 — Framework Sidebar

**Two tabs:** SPICED | MEDDPICC (tabs switch the visible field set; content of each tab persists independently)

**SPICED fields (6):**
- S — Situation
- P — Pain
- I — Impact
- CE — Critical Event
- D — Decision Criteria / Decision Process

**MEDDPICC fields (8):**
- M — Metrics
- E — Economic Buyer  
- D — Decision Criteria
- D — Decision Process
- P — Paper Process
- I — Implicate the Pain
- C — Champion
- C — Competition

**UX:**
- Each field is a small textarea (2–3 rows, resizable)
- Fields with content get a green border (visual progress indicator)
- No auto-save needed — all state lives in the page until reset

## Feature 4 — Evaluation Panel

Triggered by the "Avaliar →" button in the topbar.

**Request:** `POST /avaliar`
```json
{
  "transcript": [...chat history...],
  "spiced": { "S": "...", "P": "...", ... },
  "meddpicc": { "M": "...", "E": "...", ... },
  "scenario": { "produto": "...", "empresa": "...", "contexto": "..." }
}
```

**Gemini evaluator system prompt:**
> "You are a sales methodology expert evaluating a sales trainee's SPICED (S — Situation; P — Pain; I — Impact; CE — Critical Event; D — Decision Criteria / Decision Process) and MEDDPICC (M — Metrics; E — Economic Buyer; D — Decision Criteria; D — Decision Process; P — Paper Process; I — Implicate the Pain; C — Champion; C — Competitionnotes) after a discovery call. For each field that was filled in, score it 0–100 based on accuracy, completeness, and how well it reflects information actually present in the transcript. For empty fields, score 0. Return structured JSON only."

**Response format:**
```json
{
  "overall_score": 73,
  "spiced": {
    "S": { "score": 85, "feedback": "...", "ideal": "..." },
    "P": { "score": 0, "feedback": "Not filled.", "ideal": "..." },
    ...
  },
  "meddpicc": { ... }
}
```

**Display:** Eval panel appears at the bottom of the chat area (above the input). Shows:
- Overall score in % e.g. 87% (large, color-coded: green ≥80, amber 50–79, red <50)
- Per-field mini cards with progress bar + short feedback
- "Resposta ideal" expandable block for each field
- Panel can be dismissed; "Avaliar →" re-runs it at any time with updated notes

## UI Design

Follows SAP dark theme conventions:
- Background: `#0d1117`, Surface: `#161b22`, Border: `#30363d`
- SPICED accent: `#0070f3` (SAP Blue)
- MEDDPICC accent: `#e8a000` (amber)
- Score colors: green `#238636`, amber `#e8a000`, red `#da3633`
- Font: system sans-serif (72 SAP font if available, falls back to Inter/system)

## Routes

| Route | Method | Description |
|---|---|---|
| `/` | GET | Serve index.html |
| `/chat` | POST | Send message, get AI reply |

## Out of Scope

- User accounts / persistence across sessions (no database)
- History saved between sessions
- Mobile layout
- Multiple simultaneous scenarios
