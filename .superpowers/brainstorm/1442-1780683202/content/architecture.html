A — Flask + HTML/JS (Recomendado)

Backend Python leve gerencia as chamadas à API Gemini e o histórico do chat. Frontend em HTML/CSS/JS puro, sem frameworks. Mesmo padrão do seu fc-forecast.

Prós

  • Você já conhece o padrão
  • API key segura no servidor
  • Fácil de rodar localmente

Contras

  • Precisa de Python instalado
Browser
→ direto →
Gemini API
⚠ API key exposta no código JS — qualquer um que inspecionar o código vê a chave
+ Sem instalação de Python
+ Abre o HTML diretamente no browser
+ Zero backend

B — HTML puro com chamada direta à API

Sem backend. O JavaScript chama a Gemini API diretamente do browser. Abre o arquivo HTML e pronto — sem instalar nada.

Prós

  • Zero setup
  • Arquivo único

Contras

  • API key visível no código
  • Uso pessoal = risco baixo, mas existe

C — Next.js / React

Stack moderna com React. Mais robusto mas também mais pesado — requer Node, npm install, build. Overkill para uma ferramenta de treino pessoal.

Prós

  • Stack moderna
  • Componentes reativos

Contras

  • Setup complexo
  • Excessivo para o caso
